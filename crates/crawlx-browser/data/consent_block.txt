# One URL pattern per line; blank lines and lines starting with `#` are ignored. A pattern is

# `Network.setBlockedURLs`, i.e. of `PageOp::BlockUrls`). Every entry is written
# `*://<host>/<path>`: `*://` covers http, https and any other scheme, and a leading `*.` in the
# host covers every subdomain. Keep entries specific to a consent-management provider's script,
# stylesheet or API host: a pattern that also matches application traffic breaks pages.
